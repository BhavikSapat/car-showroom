# 🚗 Car Showroom Management System - Frontend

A modern React-based frontend for a full-stack **Car Showroom Management System** built to manage customers, vehicles, bookings, customer-car relationships, authentication, and showroom analytics.

This frontend is developed using **React, TypeScript, Vite, Tailwind CSS, and REST API integration** and communicates with a Spring Boot backend powered by PostgreSQL.

## 📌 About The Project

The Car Showroom Management System is a full-stack application designed to simplify and centralize showroom operations.

The frontend provides a clean and responsive interface through which authorized users can manage customers, vehicles, bookings, customer-vehicle relationships, and analytical reports.

The application communicates with a Spring Boot REST API, while PostgreSQL is used as the primary database.

---

## ✨ Features

### 👥 Customer Management

- Add customers
- Edit customer details
- View customer details
- Delete customers
- Search customers
- Filter customers
- Sort customer records
- Pagination
- View assigned vehicles

### 🚗 Car Management

- Add vehicles
- View vehicles
- Edit vehicle information
- Delete vehicles
- Search and filter vehicles
- View vehicle details
- Manage showroom inventory

### 🔗 Customer-Car Relationship

- Assign vehicles to registered customers
- View active customer-car assignments
- Display customer and vehicle information together
- Track booking dates
- Unlink assigned vehicles
- Refresh relationship data

### 📊 Dashboard

- Customer statistics
- Vehicle statistics
- User information
- Vehicle allocation information
- Showroom overview

### 🔎 Search & Filtering

Customer records can be searched and filtered by:

- Name
- Email
- Booking Date
- Customer ID

Vehicle records can be filtered by:

- Company / Brand
- Model

### 📈 Advanced Analytics & Reports

The frontend provides an Advanced Queries section for executing backend-powered database queries.

Available reports include:

- Customers With Cars
- Filter Customers by Vehicle Brand
- Filter Customers by Vehicle Model
- All Customers & Allocations
- Vehicle Registration Breakdown
- Customer Summary Report
